gRPC Weather Server

A C# service that serves weather data via gRPC. It runs in an Azure Container App, which supports the HTTP/2 that gRPC needs. A separate C# client calls it.

Endpoints

gRPC WeatherService.GetWeather
The current weather from Open-Meteo, in Protobuf. Called by the client.
GET /weather?latitude=53.41&longitude=-2.15
An HTTP copy of the gRPC endpoint, to check the Open-Meteo lookup works and see what the data looks like.
GET /ping
Checks the server is alive. It also wakes it up: the server sleeps when idle, and a gRPC call alone won't wake it.
Benchmark endpoints
REST /forecast-echo?count=N and gRPC EchoForecast / StreamForecast return the same made-up forecast, for the client's gRPC vs REST benchmark.
